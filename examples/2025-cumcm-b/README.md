## 核心数值（可复现锚点）

- SiC（TO-LO 通道）：7.202 / 7.165 μm，合并 7.20±0.09 [7.01, 7.38]
- SiC（包络通道，命题人口径）：7.613 / 7.437 μm，均值 7.53 —— 与薛毅 7.469 [7.250, 7.687]、竺 7.604 同通道一致
- SiC（常数 n=2.55）：8.019 / 8.099 μm（反例：忽略色散的代价）
- Si（多光束 Airy+Drude）：3.414 μm，R²=0.9969/0.9977（双光束仅 0.951）
- 判据：锐度系数 Si F=0.166 vs SiC F=0.004（38 倍）；谐波相对强度 0.986 vs 0.360；可见度 0.52
