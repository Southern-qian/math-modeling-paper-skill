# 阶段 10：导师/评委意见定点修订工作流

> 实战来源：2025 高教社杯 B 题成稿经导师审阅（"省一水平，国奖不好说"）后，按三条意见 + 两篇指定参考文献（命题人解析 + 期刊范本）定点修订为 v3。完整案例见 `examples/2025-cumcm-b/`（含 v1/v2/v3 三版快照与修订对照表）。

## R1 意见解码：评语 → 病灶节号

把每条评语翻译成"论文里的具体位置 + 具体缺陷"。方法：逐条意见问三个问题——它在说哪一节？该节现在缺什么/多了什么？评委（或导师）读到这里时看到了什么？

示例（真实评语 → 病灶）：

| 评语 | 病灶定位 |
|---|---|
| "第一问对构建数学模型的结果不太明确，基础不牢" | 问题一只有推导过程，无"模型 = 反演系统"的总结（输入/输出/适用条件缺失） |
| "每一步的来源和步骤之间的关系交代不清，像罗列公式" | "我们采用 X"式陈述；技术选择无动机闭环；节间无上下游连接；公式无去向交代 |
| "验证过剩、细节欠打磨" | 判定与复核叙述重叠；灵敏度/蒙特卡洛两节重复讲误差；摘要过长 |

## R2 参考文献深读：先分清两类文献

导师给的参考文献通常分两类，读法完全不同：

1. **评分标准类**（命题人解析、评审综述）——提取"标准答案结构"与"失分点清单"。命题人解析的最后一节通常直接点评参赛论文常见错误，逐条对照自己的论文。例：薛毅解析指出"R_theo 的数学表达式学生往往没写清楚"、"必要条件要定量指标"、算法要满足"实用性/鲁棒性/一致性"三条——每一条都是一个修改动作。
2. **写作范式类**（同题期刊论文）——提取"每一步的呈现范式"。优秀期刊论文的每个技术选择都是四段式闭环：**动机（为什么需要）→ 数据事实（实测检验）→ 决策（怎么做）→ 理由（为什么不那么做）**。逐节模仿这个骨架。

深读产出：一张"标准结构对照表"——范文有而本文没有的节/图/论证，逐项列出。

## R3 修改矩阵：意见 → 根因 → 动作 → 依据 → 验收

把 R1 的病灶与 R2 的对照表合成一张矩阵，每个动作标注：改动节号、参考依据（范文第几节）、验收标准（怎样算改好）。评审分值高的意见（如"Q1 30 分"）对应的动作排最前。

## R4 归因实验先行：先锁定新数值，再动笔

修订中最有力的回应不是解释，而是**新实验**。设计原则：控制变量——固定算法、只换一个先验输入，看结果移动多少。

实战案例（折射率通道归因实验）：同一级数标定算法，三条折射率通道给出 SiC 厚度 7.20（TO-LO 振子）/ 7.53（包络反演，命题人通道）/ 8.06（常数）μm——包络通道与命题人加权结果 7.469 [7.250, 7.687] 一致，且反演折射率与命题人解析逐点吻合。一处实验同时做到：方法间离散的定量归因、与权威结果互证、"我们的数值为什么不同"从弱点变成论证。

其他低成本高收益实验：波峰法 vs 峰谷法对比（验证稳健性论断）、参数扫描曲线（可辨识性）、判据量级对比表（如 Airy 锐度系数 F 两体系差 38 倍）。

## R5 定点改写：三类标准动作

按修订矩阵执行，动作分三类：

- **模型显式化**（回应"结果不明确"）：新增"模型小结"节 = 组装流程图（TikZ）+ 四要素表（输入/输出/适用条件/局限）+ 被删/被略公式的补回；后续每节开头显式回指"调用模型组件几"。
- **逻辑链显式化**（回应"罗列公式"）：全文逻辑主线图（节号+公式号标注依赖关系）；按四段式补齐每个技术选择的动机闭环；关键节首尾加"本节输入/产出"句。
- **精简打磨**（回应"验证过剩"）：合并叙述重叠的节；验证实验压成"一张表+一段话"；摘要收紧到每问"模型一句+算法一句+数值一句"；删冗余第一人称。

## R6 验收与交付

编译零警告 → 数值一致性互查（新增数值尤其要查：出现在摘要/正文/图表几处，必须一致）→ 全页渲染视觉验收（修订导致版面后移时**全量重渲染**）→ 产出 **修订对照表**（意见→动作→落点节号，可直接发给导师）。

## 回档机制

每轮成稿在 `examples/<题目>/versions/` 存快照：`vN_页数_名称.tex + .pdf` 配对存放；git 仓库本身提供历史回滚（`git log` / `git checkout <commit>`）。回档规则：**tex 与 pdf 必须成对存**，命名带版本号与一句话特征；最终交付版另存 `final.pdf`。
