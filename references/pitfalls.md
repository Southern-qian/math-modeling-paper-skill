# 实战踩坑清单（每条都真实翻过车）

## 量纲与物理（占历史 bug 的 60%）

1. **cm ↔ μm 换算**：波数公式里 d 的单位必须与 σ 匹配（d[cm]·σ[cm⁻¹] 无量纲）。同一段代码里"斜率已经是 μm"和"还要乘 1e4"两种写法混用，导致厚度差 1 万倍（0.0014 μm vs 7.2 μm）。规则：**每个物理量在进入公式前显式换算成 cm，只在打印/作图时转 μm**。
2. **峰谷交替是半级**：相邻极值（峰→谷）级数差 0.5 不是 1。峰-峰才是整级。搞错直接差一倍。
3. **色散下极值间距由群指数决定**：n_g = n + σ·dn/dσ，不是相速折射率 n。在强色散区（声子尾缘）两者差可达 10–40%。朴素逐对法用相速指数 → 厚度系统偏大 ~14%。用精确相位差分公式 d = N/(2[f(σⱼ)−f(σᵢ)])，f(σ)=σ√(n²−sin²θ₁)，对任意色散严格成立。
4. **线性标定 profiling 的还原方向**：若 raw = model − meas，则 model = meas + raw。写反成 meas − raw 会让优化器目标全错，R² 变负数。
5. **per-dataset 数组不要用全局偏移切片**：拼接残差时 raw[i:i+n] 用全局偏移，但每个数据集自己的 rr 是从头开始的——切片写 rr[i:i+n] 会切出空数组（broadcast 报错）或静默错误。
6. **δn=0 时 Airy 退化为双光束**（界面无反射），"多光束 vs 双光束对比"就失去意义。对比实验要给衬底一个物理上非零的折射率差（如重掺杂 Drude 位移 −0.5%）。
7. **优化参数钉死在边界上 = 模型或边界错了**：检查 DE/TRF 结果里贴边界的参数。物理约束（如 ε∞ 的合理区间）要用文献值收窄，而不是放宽边界让优化器乱跑。
8. **包络法反射率单位**：公式 √R 要求 R∈[0,1]，实测是百分数（18.5 表示 18.5%）必须先 /100，否则折射率算出负数。
9. **多进程回调**：scipy differential_evolution 的 `workers=-1` 在 macOS spawn 模式下会重新执行 `__main__`——脚本必须有 `if __name__ == "__main__"` 保护，否则进程爆炸。单机数据量小直接 `workers=1`。
10. **DE 回调签名**：不同 scipy 版本回调是 `cb(xk, convergence)` 或 `cb(intermediate_result)`，版本不匹配直接 TypeError。

## LaTeX/排版

11. **中文引号**：正文里的 "引号" 必须用 Unicode “ ”，ASCII `"` 会被 LaTeX 当右引号（渲染成 ”引号”）。写完用脚本全局扫一遍。
12. **下划线**：正文/表格里出现仓库名（SiC_Thickness_Analysis）必须写 `\_`，否则 Missing $ inserted。URL 里不用（\url{} 内部处理）。
13. **TikZ 宽度累积**：节点 text width + inner sep + 间距会累加超出 \columnwidth，报 Overfull 仅 1–2pt。收 inner sep 与间距。
14. **宽公式**：双部件公式（A=..., B=... 用 \qquad 连接）在 A4 单栏也可能超宽 20pt。拆成 equation + 行内定义。
15. **表格浮动导致空节**：`\section{符号说明}` 后直接跟 `[htbp]` 大表 → 标题与下一节标题连排、表飘到两页后。加引导句 + `[!htb]`。
16. **xurl** 处理参考文献 URL 断行；`needspace` 防附录小节标题孤悬页底。
17. **Tectonic 冷启动**：首次编译下载宏包可能超包装脚本的 2 分钟超时——先直接跑一次 tectonic 预热 ~/.cache/Tectonic，再用包装脚本出干净结果。

## 数值一致性（judge/评审最爱抓的）

18. **正文百分比必须能从表内数据复算**：写"互差不超过 2%"之前用计算器算一遍表里两数之差/较小值。历史教训：正文写 2.0%，表里实为 2.6%，被审稿抓两次。
19. **同一 R² 只能有一套数**：图例、正文、表格、摘要的 R² 小数位要对齐（建议统一 4–5 位）。
20. **图例单位与正文一致**：图轴标签 μm/cm⁻¹、百分比 vs 小数，正文引用时别换算错。
21. **版面后移后 PNG 全部过期**：只重渲染改动页会让视觉审稿读到陈旧页面、报"不可能的重复内容"。正文改动影响分页时全量重渲染。

## 流程

22. **GitHub 网页搜索限流**（Too many requests）：改走 api.github.com 的 REST 搜索与 readme 接口；中文路径要 URL-encode；raw.githubusercontent.com 可能被墙，API contents 接口更稳。
23. **Crossref 核验不过的文献直接删**：宁缺毋滥，虚构文献是评审死刑。
24. **与开源对照要诚实**：结果差 2–5% 时把差异归因到折射率模型选择并量化，写进"模型不足"——评审欣赏暴露离散而不是掩盖。

## 修订轮新增（v3 实战）

25. **TikZ 节点里的带圈数字**：`font=\sffamily` 的节点用 Latin 字体，①②③④ 无字形（Missing character）——正文可用、TikZ 内一律用普通数字。
26. **TikZ 样式名禁用 `out`**：`\node[out,...]` 会撞上 TikZ 内置键 `/tikz/out`（"key requires a value"报错）——样式改名（如 `res`）。
27. **自定义单位宏只能在数学模式用**：`\um`/`\invcm` 定义含 `\mathrm`，正文文本里直接写即 fatal——使用处必须包 `$…$`；编译后全文 grep 检查。
28. **删公式留引用 = "??"**：精简时删了被引用的公式，`\eqref` 渲染为 (??)——每次删公式先全文搜其 label；编译后全文搜 "？?"。
29. **matplotlib 图内硬编码文献编号**："文献[15]"式标签在参考文献增删后与文献表错位（评审一眼抓到）——图标签用实现名称，编号交给正文。
30. **修订导致版面后移**：正文改动后若只重渲染改动页，视觉审稿会读到陈旧页面并报"不可能的重复内容"——影响分页的修改必须全量重渲染。
31. **长内联公式断行**：加粗段落里 ~170pt 的不可断公式产生 Overfull，`\emergencystretch` 救不了——把一个长公式拆成两个短公式（中间放可断行的汉字）。
