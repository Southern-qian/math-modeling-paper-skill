# 人工验收清单（judge 替身 · 拿到 PDF 后逐条打勾）

> 用途：GPT 或其他 LLM 产出论文 PDF 后，你按此清单人工验收。25 条按严重程度分三档，**A 档任何一条不过就打回重做**。全程约 30–40 分钟。

## A 档：硬伤（一票否决）

- [ ] A1 摘要里每个数值，在正文/表格里能找到完全一致的出处（逐个数字对，小数位也要一致）
- [ ] A2 表格里每处"偏差/百分比"用计算器从表内两数复算一遍（差 ÷ 较小值）
- [ ] A3 图注里的数值（均值、R²）与对应表格一致
- [ ] A4 随机挑 2 个你认为最关键的数值，用附录代码（或让 GPT 给最小复现脚本）本地跑一遍核对
- [ ] A5 参考文献抽 3 条：DOI 粘到 https://search.crossref.org 或 doi.org，标题/作者/年份/卷期页必须对得上；对不上的一律删掉或标注
- [ ] A6 每张图的中文标签正常显示（无方框 □）
- [ ] A7 中文无乱码、无豆腐块（重点看表格和代码附录）
- [ ] A8 示意图的每个标注（符号、厚度、角度）与公式的定义逐字一致
- [ ] A9 文中没有"待补""待定""XX"占位符
- [ ] A10 编译零 Overfull（右边缘无文字出血）；若用 Overleaf 看红色/橙色警告日志

## B 档：评审观感（建议全过）

- [ ] B1 摘要分段有"针对问题一/二/三"加粗引导，每个结论带数值
- [ ] B2 关键词行完整不拆字
- [ ] B3 章节编号连续；"符号说明"等节标题下有内容（无空节）
- [ ] B4 图/表编号连续，正文每处"如图 X 所示"的 X 真实存在且位置合理
- [ ] B5 三线表完整（顶线/中线/底线），无单元格溢出
- [ ] B6 公式有编号、正文用 \eqref 引用、无超宽公式
- [ ] B7 参考文献 20 条左右、格式统一（GB/T 7714）、URL 断行不丑
- [ ] B8 上标引用（正文中的引用是上标形式）
- [ ] B9 代码附录：行号、无溢出、中文注释正常
- [ ] B10 页边距左右对称、无大面积空白页、无孤行标题

## C 档：加分项（冲击国奖时逐条争取）

- [ ] C1 正文有一张"与文献/开源实现结果对照"的表或图，方法间差异已量化并归因
- [ ] C2 至少一个改进点带机理分析（为什么基线方法错、改进公式为什么对）
- [ ] C3 有参数可辨识实验（扫描曲线图）
- [ ] C4 可靠性四件套齐全（双数据互证 / Bootstrap / 灵敏度表 / 蒙特卡洛）
- [ ] C5 模型不足一节诚实量化了方法间系统差异（而不是假装只有一个答案）
- [ ] C6 摘要信息密度：不看正文也能复述出"每问用了什么方法、算出什么数、可靠性如何"
- [ ] C7 全文篇幅 ≥20 页、图 ≥12 张
- [ ] C8 附录代码与正文方法一一对应，能独立跑通
